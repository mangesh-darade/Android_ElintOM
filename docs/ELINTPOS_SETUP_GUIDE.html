ElintPOS Android Setup Guide

User Guide: Initial Printer Configuration & Login Process

Official Guide
1

App Boot & Initial Printer Setup Screen

Upon first launching the app after installation or storage reset, the system automatically opens the Printer Setup screen.

  • Connection Box: Choose printer interface type and model.
  • Paper Spacing: Configure blank paper margin around the printed receipt (Default: Top 8 dots / Bottom 20 dots).
  • After the bill: Select paper cutter action (Full cut, Partial cut, or Continue).
  • Register Options:
    • Show a print dialog before each bill (shows a preview/confirmation before printing).
    • Open this register when the device starts (launches ElintPOS automatically upon device boot).
2

Select Connection Type & Printer Model

Tap the Type dropdown inside the Connection box to select your hardware interface.

  • Bluetooth: Wireless external thermal receipt printers (58mm / 80mm). (Ensure Bluetooth is enabled and paired.)
  • USB: Direct USB / OTG connection to thermal printers.
  • LAN: Wi-Fi or Ethernet network printers (IP port 9100).
  • TecMI K8: Built-in printer for all-in-one POS terminals.
  • Model: Select paper roll model (e.g. XP-80 for standard 80mm roll).
3

Select Printer, Test Print & Continue

The selected interface displays active printers in the Available printers list.

  • Select Printer: Tap your printer in the list (e.g. TecMI K8 Built-in Printer or paired Bluetooth device). The border turns green.
  • Test print: Tap Test print to verify paper feed, alignment, and print clarity.
  • Continue: Tap the green Continue button to finalize and proceed.
Permanent Persistence: The printer configuration is permanently stored in Android SharedPreferences. This setup screen is skipped on subsequent app launches.
4

POS Sign In & Start Billing

After setup confirmation, the app immediately transitions to the ElintPOS Sign In page.

  • Username: Enter credentials (e.g., Admin).
  • Password: Enter password (e.g., Admin@554).
  • Log In: Tap the blue Log In button.
Ready for Billing: Successful login opens the main POS billing register with auto-printing fully configured and active!
